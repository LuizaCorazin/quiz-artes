# 🎨 Quiz de Artes – README

## 📌 Sobre o Projeto

O **Quiz de Artes** é um aplicativo interativo desenvolvido para testar conhecimentos sobre história da arte, com foco em movimentos como a **Pop Art**. O app apresenta perguntas de múltipla escolha em uma interface simples, moderna e visualmente agradável.

Ele foi pensado para ser intuitivo, educativo e acessível, podendo ser utilizado tanto para estudo quanto para entretenimento.

---

## 🎯 Objetivo

O principal objetivo do app é:

* Estimular o aprendizado sobre arte de forma dinâmica
* Testar conhecimentos de maneira rápida e interativa
* Tornar o estudo mais leve e visual

---

## 🖥️ Funcionalidades

### ✅ Tela Inicial

* Exibe o título **“Quiz de Artes”**
* Contém uma imagem temática relacionada à arte
* Botão **“Entrar”** para iniciar o quiz

### ❓ Sistema de Perguntas

* Perguntas de múltipla escolha
* Interface clara com alternativas em botões
* Apenas uma alternativa correta por pergunta
